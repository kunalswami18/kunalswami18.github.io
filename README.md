# kunalswami18.github.io

Personal site. Plain HTML/CSS/JS, no build step.

- `data.js` – all content (publications, experience, news, links). Edit this to update the site.
- `index.html` – page structure. `style.css` – design. `script.js` – rendering and interactions.
- Analytics: set `GOATCOUNTER_CODE` at the top of `script.js`.
